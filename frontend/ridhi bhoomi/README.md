# Ridhi Bhoomi — Property Website

Production-ready real-estate website for **Ridhi Bhoomi** by **Wellburg Reality Pvt. Ltd.**

## Architecture

```
ridhi-bhoomi/
├── client/          React.js + Vite + Tailwind CSS
├── server/          Node.js + Express + SQLite
├── .env.example
└── README.md
```

**Stack:** React.js (JavaScript) · Vite · React Router · Tailwind CSS · Framer Motion · Express · SQLite

## Features

### Public Website
- Premium homepage sales funnel
- Interactive residential & commercial SVG plot maps
- Integrated live Google Maps navigation
- Price calculator & EMI estimator
- Site visit booking & lead forms
- WhatsApp integration
- Project documents & brochure downloads

## Quick Start

```bash
cd ridhi-bhoomi
npm run dev
```

- Frontend: http://localhost:5173

## Production

```bash
npm run build
npm run preview
```
